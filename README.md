## 📖 소개

**KAS**는 계원예술대학교 디지털미디어디자인과 네이버 카페에 업로드된 과제 게시물을 빠르게 검색하고, 첨부파일을 일괄 다운로드할 수 있는 macOS 전용 앱입니다.

매번 카페에 직접 접속해 게시판을 탐색하는 번거로움 없이, 이름 하나로 자신의 과제 제출 내역을 한눈에 확인하고 파일을 정리된 폴더 구조로 저장할 수 있습니다.

---

## ✨ 주요 기능

### 🔍 과제 검색
- 학생 이름으로 네이버 카페 게시글 검색 (최대 100건)
- NFC/NFD 두 가지 인코딩으로 동시 검색 → 한글 이름 누락 방지
- 게시판(과목)별 탭 필터링
- 최신순 / 오래된순 정렬
- 첨부파일 있는 글만 보기 / 미다운로드 글만 보기 필터
- 최근 검색 이름 태그 (최대 10개, 호버 시 삭제)

### ⬇️ 파일 다운로드
- 개별 게시글 첨부파일 다운로드 (원형 진행바 표시)
- 검색 결과 전체 일괄 다운로드
- 저장 경로 구조: `저장위치 / 학생이름 / 과목명 / 파일`
- 다운로드 완료 후 Finder 자동 열기 (설정에서 on/off)
- 취소 버튼으로 진행 중 다운로드 중단 가능

### 👁️ 파일 미리보기
- 다운로드된 파일을 Quick Look으로 즉시 미리보기
- 첨부파일이 여러 개인 경우 파일 선택 메뉴 제공

### ★ 즐겨찾기 (북마크)
- 게시글 행의 ★ 버튼으로 즐겨찾기 추가/해제
- **즐겨찾기 탭**에서 모아보기
- 앱을 종료해도 즐겨찾기 영구 저장

### 📋 내 제출 현황
- 설정에서 내 이름을 등록 후 클립보드 아이콘(📋)으로 창 열기
- **올해 연도** 기준으로 게시판(과목)별 제출 내역 자동 집계
- 각 과목 카드를 펼치면 세부 글 목록과 제출일 확인
- 상단에 총 제출 수 요약 배지 표시

### 🔄 다운로드 내역 동기화
- 설정 → "기존 다운로드 파일 스캔 및 동기화" 버튼
- 이미 다운로드된 폴더를 스캔해 "이전에 다운로드 완료됨" 뱃지 복원

### 🌐 네이버 로그인
- 앱 내 WebView로 네이버 로그인 (NID_AUT / NID_SES 쿠키 획득)
- 로그인 세션이 있어야 **멤버 공개** 게시글 검색 및 다운로드 가능
- 비로그인 상태에서는 전체 공개 게시글만 검색 가능

### ⚙️ 설정
- **내 이름 설정**: 내 제출 현황 조회에 사용
- **저장 경로 변경**: Downloads/KAS 외 사용자 지정 경로 설정 (Security-Scoped Bookmark)
- **Finder 자동 열기** 토글
- 다운로드 내역 동기화 버튼

## 🚀 시작하기

### 요구사항
- macOS 13 (Ventura) 이상
- 네이버 계원예대 카페 가입 계정

### 설치
1. 위 다운로드 링크에서 `KAS.dmg` 또는 `KAS.zip` 다운로드
2. 앱을 `/Applications` 폴더로 이동
3. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜰 경우:
   - 시스템 설정 → 개인정보 보호 및 보안 → "확인 없이 열기" 클릭
   - 또는 터미널에서: `xattr -d com.apple.quarantine /Applications/KAS.app`

## 📖 사용법

### 기본 검색 및 다운로드

1. 앱 실행 후 우측 상단 **"네이버 로그인"** 버튼으로 로그인
2. 검색창에 **학생 이름** 입력 후 Enter 또는 "과제 검색 및 조회" 버튼 클릭
3. 검색 결과에서 게시판 탭으로 과목 필터링
4. 개별 게시글 오른쪽 ↓ 버튼으로 단건 다운로드, 또는 "첨부파일 모두 다운로드" 로 일괄 다운로드

### 즐겨찾기

1. 게시글 행 오른쪽 ★ 버튼 클릭 → 즐겨찾기 추가 (노란 별)
2. 상단 **"즐겨찾기"** 탭에서 저장된 게시글 목록 확인

### 내 제출 현황 조회

1. **설정(⚙)** → "내 이름" 입력 후 닫기
2. 도구 모음의 **클립보드(📋) 아이콘** 클릭
3. 올해 제출한 게시글을 게시판(과목)별로 확인

### 저장 경로 변경

1. **설정(⚙)** → "저장 경로" 항목의 "선택..." 버튼 클릭
2. 원하는 폴더 선택 → 이후 다운로드 파일이 해당 경로에 저장됨
3. 기본 경로로 되돌리려면 "초기화" 버튼 클릭

### 기존 다운로드 파일 인식 (동기화)

이미 다운로드한 파일이 있지만 "이전에 다운로드 완료됨" 배지가 표시되지 않는 경우:
1. **설정(⚙)** → "기존 다운로드 파일 스캔 및 동기화" 클릭
2. 설정된 경로 하위의 `.kas_download_history.json` 파일을 읽어 내역을 복원

## 📁 저장 폴더 구조

```
저장 경로 (기본: ~/Downloads/KAS/)
└── 학생이름/
    ├── 과목명A/
    │   ├── 과제파일1.pdf
    │   └── .kas_download_history.json  ← 내부 메타데이터 (숨김)
    └── 과목명B/
        └── 과제파일2.hwp
```

## 🔒 개인정보 및 보안

- 네이버 로그인 쿠키(NID_AUT, NID_SES)는 **앱 내부 UserDefaults**에만 저장되며 외부로 전송되지 않습니다.
- 모든 검색 및 다운로드 요청은 네이버 공식 API 및 카페 서버를 통해서만 이루어집니다.
- App Sandbox가 활성화되어 있어 허용된 폴더 외에는 파일 시스템 접근이 제한됩니다.
